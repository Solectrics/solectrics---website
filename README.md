# solectrics---website
Solectrics website - Smart Solar Living on Waiheke Island and throughout NZ

## Solectrics Job Hub job types

- Home Energy Check submissions create `solar` jobs and retain the solar assessment,
  system design, Fletcher/J.A. Russell and solar supplier-pricing workflow.
- The Job Hub dashboard can create `general_electrical` jobs directly without a
  Home Energy Check. These use the electrical job brief, photos/documents, Tom's daily
  EWRB records, internal costing and versioned customer quote workflow.
- Ben remains the default supervisor in Tom's daily work records.
